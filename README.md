# 政策脈搏｜JRE 筆試升級 Demo

本地可運行的靜態示範：把近約12個月香港官方／政策相關公開資料（撮要）整理成投考人（JRE **筆試**）可用的懶人包、本週焦點長文、練習模式與溫習輸出。

> 本 Demo **不連接**政府網站 API、**無登入**、**無即時匯入**。`data/policies.js` 內為靜態撮要（76 則，約 2025-09 至 2026-10-19），附官方來源連結；非逐字轉錄，詳情以原文為準。

## 如何運行

```bash
cd /workspace/jre-policy-pulse
python3 -m http.server 5173
# 或：npx --yes serve -p 5173
```

瀏覽器開啟：<http://localhost:5173>

任何靜態伺服器皆可。部分瀏覽器直接 `file://` 開啟亦可，但建議用靜態伺服器。

## 主要功能路徑

| 功能 | 側欄入口 | 說明 |
|------|----------|------|
| **本週焦點**（新） | 🎯 本週焦點 | 一頁長文：背景→爭議→取捨→指標→練習題；同頁附先落判斷與 01／02／03 正反論點 |
| **懶人包** | ⚡ 懶人包 | 頂部先落判斷、支持理據／風險反駁／可行建議（含閘門），再「若你係決策者會點做」、GSMEAC、答題骨架 |
| **本週必記**（新） | 📄 本週必記 | 一鍵 5–8 則精選 + 必記要點；列印／複製 Markdown |
| 溫習量切換 | 懶人包／各溫習頁頂部 | **每日少量**（3 則、精簡五維、3 題）⇄ **考前密集**（8 則、完整 GSMEAC、5 題） |
| 搜尋同脈絡 | 搜尋同脈絡 | 關鍵詞 + 分類；相關政策（標籤）；可加入比較 |
| 政策比較 | 政策比較 | 兩則並排差異表 |
| JRE 練習模式 | JRE 練習模式 | 選政策 → 可選 25 分鐘計時 → GSMEAC 逐步書寫 → 骨架示例 → 自評清單 → **換題測試**（數據、持份者、制度限制） |
| 11 大議題 | 搜尋同脈絡的分類篩選 | 房屋土地、環境生態、醫療衞生、社會福利、勞工就業、經濟財政、創新科技、交通運輸、教育、治安保安、公共管治 |
| 閃卡溫習 | 閃卡溫習 | 由記憶點／政策重點生成翻面卡（隨溫習量模式重建） |

## 建議演示順序（新功能）

1. 首頁按「**打開本週焦點**」→ 看彩色長文區塊（背景／爭議／取捨／指標／練習題）→ 頂部按鈕切換不同焦點篇  
2. 按「**一鍵本週必記**」→ 檢視 8 則必記清單 →「複製 Markdown」或「列印／匯出 PDF」  
3. 側欄「**懶人包**」→ 開啟任一則 → **最上方**先見「若你係決策者會點做」2–3 題，再往下 GSMEAC 與「問題—取捨—方案—指標」  
4. 切換 **每日少量／考前密集**，確認舊功能仍在  
5. 「開始筆試練習」→ 閃卡 → 政策比較（回歸測試）

## 技術

- 純靜態：`index.html` + `css/styles.css` + `js/app.js` + `data/policies.js`
- 無框架、無建置步驟、無後端
- UI：繁體中文（zh-Hant-HK），主色 `#0d5b4c` / `#103e34`，襯線標題
- 本週策展資料：`window.WEEKLY_BUNDLE`（`data/policies.js` 末）

## GSMEAC（筆試用法）

治理、持份者、執行、成效、問責／協同（本 Demo 另加「協同延伸」一步作優化建議練習）。答題骨架固定為：**問題 — 取捨 — 方案 — 指標**。
