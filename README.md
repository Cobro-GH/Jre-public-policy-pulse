# 政策脈搏｜JRE 筆試升級 Demo

本地可運行的靜態示範：把近約12個月香港官方／政策相關公開資料（撮要）整理成投考人（JRE **筆試**）可用的懶人包、練習模式與溫習輸出。

> 本 Demo **不連接**政府網站 API、**無登入**、**無即時匯入**。`data/policies.js` 內為靜態撮要（約 65 則，約 2025-09 至 2026-10），附官方來源連結；非逐字轉錄，詳情以原文為準。

## 如何運行

```bash
cd /workspace/jre-policy-pulse
python3 -m http.server 5173
# 或：npx --yes serve -p 5173
```

瀏覽器開啟：<http://localhost:5173>

任何靜態伺服器皆可。部分瀏覽器直接 `file://` 開啟亦可，但建議用靜態伺服器。

## 主要功能路徑

| 功能 | 側欄入口 | 說明 |
|------|----------|------|
| **懶人包**（主打） | ⚡ 懶人包 | 一則政策一頁掃描：重點、記憶點、關鍵詞、GSMEAC 書面角度、筆試題 + **答題骨架** |
| 溫習量切換 | 懶人包／各溫習頁頂部 | **每日少量**（3 則、精簡五維、3 題）⇄ **考前密集**（8 則、完整 GSMEAC、5 題） |
| 搜尋同脈絡 | 搜尋同脈絡 | 關鍵詞 + 分類；相關政策（標籤）；可加入比較 |
| 政策比較 | 政策比較 | 兩則並排差異表 |
| JRE 練習模式 | JRE 練習模式 | 選政策 → 可選 25 分鐘計時 → GSMEAC 逐步書寫 → 骨架示例 → 自評清單 |
| 閃卡溫習 | 閃卡溫習 | 由記憶點／政策重點生成翻面卡（隨溫習量模式重建） |
| 一頁簡報 | 一頁簡報 | 列印友好 HTML；複製 Markdown |

建議演示順序：

1. 首頁英雄區按「打開懶人包」，切換 **每日少量／考前密集**
2. 開啟任一懶人包，捲動查看 GSMEAC 與「問題—取捨—方案—指標」骨架
3. 「開始筆試練習」走完一兩個維度並勾自評
4. 搜尋關鍵詞（如「北都」「基層醫療」）→ 相關政策 → 比較
5. 「生成本模式溫習包簡報」→ 列印／複製 Markdown

## 技術

- 純靜態：`index.html` + `css/styles.css` + `js/app.js` + `data/policies.js`
- 無框架、無建置步驟、無後端
- UI：繁體中文（zh-Hant-HK），主色 `#0d5b4c` / `#103e34`，襯線標題

## 與正式版 Manus「政策脈搏」的差異（限制）

| 正式版（參考） | 本 Demo |
|----------------|---------|
| 即時／排程匯入官方來源 | ❌ 靜態約 65 則近一年撮要（含來源 URL） |
| 登入、覆核佇列、來源健康 | ❌ 無 |
| AI 每週洞見、Excel／Word 匯出 | ❌ 改為懶人包 + 可列印簡報 + Markdown |
| 完整政策總表與趨勢 | △ 有搜尋／分類／比較，無趨勢圖 |
| 口試提示 | ❌ **刻意不做**；本版對準 **JRE 筆試**書面結構 |

## GSMEAC（筆試用法）

治理、持份者、執行、成效、問責／協同（本 Demo 另加「協同延伸」一步作優化建議練習）。答題骨架固定為：**問題 — 取捨 — 方案 — 指標**。
